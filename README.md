# rexpdes

R codes for the book *"Experimental Design for Data Science and Engineering"* by V. Roshan Joseph

📖 https://doi.org/10.1201/9781003661535

---

## Repository Structure

```
rexpdes/
├── R/              # Chapter-by-chapter R source scripts
│   ├── Ch1.R       # Introduction
│   ├── Ch2.R       # Modeling
│   ├── Ch3.R       # Model-based Designs
│   ├── Ch4.R       # Space-Filling Designs
│   ├── Ch5.R       # Representative Points
│   ├── Ch6.R       # Screening Designs
│   ├── Ch7.R       # Sequential Designs
│   ├── Ch8.R       # Fractional Factorial Designs
│   ├── Ch9.R       # Model Calibration
│   ├── Ch10.R      # Data Subsampling
│   └── Ch11.R      # Data Analysis
├── markdown/       # R Markdown documents (Ch1–Ch11)
├── pdf/            # Compiled PDFs (Ch1–Ch11)
└── datasets/       # Data files used across chapters
```
